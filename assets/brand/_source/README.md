# Source artwork

`reference-board.jpeg` is the original 13-panel reference board supplied by MIHIR (1536 x 1024).
The monogram and wordmark used across the whole kit are traced from its primary-logo panel;
see the "Source artwork and tracing" section of `../README.md` for the exact commands.

If a sharper export of the logo becomes available, drop it here (plain black background, no
shadow, 1500 px or wider), re-run the trace commands against it, then `npm run brand:build`.
